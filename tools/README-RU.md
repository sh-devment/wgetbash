## wgetbash

Доставка bash-скриптов через wget.

Часто залетаю на серверы вне своей инфраструктуры — их нет в Ansible, а
операции на них повторяются. Захотелось доставлять скрипты одной командой
через wget. Ещё у меня было отдельное приложение loger для анализа логов —
совместил их в одно, так удобнее в повседневной работе.

## Что внутри

- **Скрипты по HTTPS** — храните bash-скрипты и вызывайте их по ссылке
- **Только wget** — на сервере больше ничего ставить не нужно
- **Заметки** — немного поддержки Markdown и приватные скрипты: удобно для быстрых записей
- **Офлайн-режим** — где wget не достучится, скрипт копируется через буфер обмена
- **Поиск** — быстрый и удобный, по всему содержимому
- **Логи** — всё нужное для быстрого анализа логов на лету
